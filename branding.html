Custom CSS for Advanced Date Picker (Jotform Widget)

You can customize the look and feel of the Advanced Date Picker widget by adding CSS rules in Jotform’s Custom CSS panel. Below are the available CSS classes you can target to style different parts of the calendar.

Available CSS Classes

Calendar (Flatpickr)

  • .flatpickr-day.flatpickr-disabled – Disabled days that cannot be selected.
  • .flatpickr-day.selected – Days that have been selected by the user.
  • .flatpickr-day – Normal, selectable days.
  • .flatpickr-day:hover – Days when hovered over by the mouse.
  • .flatpickr-days – Background for the calendar day grid.
  • .flatpickr-months – Background for the month and year row.
  • .flatpickr-weekdays – Background for the weekday name row.

Progress Bar

  • .adp-progress – The progress bar track (outer container).
  • .adp-progress__fill – The filled portion of the progress bar.
  • .adp-progress--under – Fill color when below the minimum required dates (yellow).
  • .adp-progress--ok – Fill color when selection is valid (green).
  • .adp-progress--full – Fill color when the maximum is reached (blue).
  • .adp-progress__label – Text label below the progress bar ("3 selected of 10 max").

Toolbar Buttons

  • .adp-toolbar – Container for the Select All / Clear All buttons.
  • .adp-btn – Primary button style (Select All).
  • .adp-btn--secondary – Secondary button style (Clear All).
  • .adp-btn:disabled – Disabled state for both buttons.

Example Custom CSS

/* Disabled days */
.flatpickr-day.flatpickr-disabled {
    background-color: white;
    color: #9f9f9f;
    cursor: not-allowed;
}

/* Selected days */
.flatpickr-day.selected {
    color: white;
    background-color: black;
}

/* Normal days */
.flatpickr-day {
    background-color: yellow;
    color: orange;
}

/* Hover effect for selectable days */
.flatpickr-day:hover {
    background-color: orange;
    border: 2px solid olive;
}

/* Calendar day grid background */
.flatpickr-days {
    background-color: #fafafa;
}

/* Month and year row background */
.flatpickr-months {
    background-color: #f0f0f0;
}

/* Weekday row background */
.flatpickr-weekdays {
    background-color: #f9f9f9;
}

/* Progress bar customization */
.adp-progress { height: 8px; border-radius: 4px; }
.adp-progress--ok { background-color: #4caf50; }
.adp-progress--full { background-color: #2196f3; }

/* Button customization */
.adp-btn { border-radius: 20px; font-weight: 600; }

How to Apply Custom Styles

Important: This widget runs inside an iframe. Jotform's form-level Custom CSS panel cannot reach inside the iframe. To customize the widget's appearance, you must edit style.css directly in the hosted widget files.
  1. Open style.css in your hosted widget files.
  2. Add or modify the CSS rules using the classes listed above.
  3. Save and reload your form to see the changes.
Tip: Test your changes using a few different months and selected dates to ensure colors and styles are applied consistently.
